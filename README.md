# Physics — подготовка к экзамену

Этот репозиторий — рабочая база подготовки по электричеству и электромагнетизму. Главная цель — последовательно изучить пять основных блоков курса, понять физический смысл законов и научиться решать типовые экзаменационные задачи.

## Основные документы

- [STUDY_PLAN.md](STUDY_PLAN.md) — маршрут подготовки на 4 недели / 20 занятий, контрольные вопросы, критерии освоения тем и отметки прогресса.
- [THEORY.md](THEORY.md) — подробная теория, определения, объяснение физических процессов, формулы, единицы измерения, сводные таблицы и типичные ошибки.
- [DAILY_PROGRESS.md](DAILY_PROGRESS.md) — журнал выданных занятий, даты, текущая позиция и следующая тема.

## Учебная база

1. В. Ф. Малишевский, «Пособие по решению задач по общей физике (электромагнетизм)», 2012 — основной каркас курса и задачи.
2. С. Г. Калашников, «Электричество», 2004 — углублённое объяснение тем и дополнительные разделы.

Основная последовательность курса определяется пятью главами пособия Малишевского: электростатика; электрическая ёмкость и энергия; постоянный ток; магнитное поле и электромагнитная индукция; электромагнитные колебания и волны.

## Порядок работы

1. Открыть STUDY_PLAN.md и пройти занятия по порядку.
2. По теме занятия изучить соответствующий раздел THEORY.md.
3. Повторить определения и формулы по памяти.
4. Решить задачи из пособия Малишевского: сначала разобранные примеры, затем самостоятельные задачи.
5. Использовать Калашникова для углубления или если объяснения основного конспекта недостаточно.
6. После каждого выданного урока обновлять DAILY_PROGRESS.md.
7. Освоение темы подтверждать только после ответов пользователя и самостоятельного решения задачи.

## Правила поддержки этого проекта

- Сохранять пять основных тематических блоков, пока официальный список экзаменационных вопросов не потребует другого порядка.
- Не превращать весь учебник Калашникова в обязательную программу: его дополнительные главы использовать по необходимости.
- При продолжении занятий сначала сверяться с DAILY_PROGRESS.md, затем с STUDY_PLAN.md и THEORY.md.
- В объяснениях давать определение, физический смысл, формулу, расшифровку символов, единицы и условия применимости.
- В задачах придерживаться метода: условие → схема → СИ → закон → решение в общем виде → вычисление → проверка размерности и ответа.
- Не отмечать тему как освоенной, пока пользователь не сможет пересказать её и решить типовую задачу самостоятельно.
